## 各ページの主要セクション

### index.html（トップ）
1. ヒーロー：キャッチコピー + CTAボタン（相談・電話）+ 写真2枚
2. サービス概要：3カード（卸調達 / イベント提案 / 機材貸出）→ services.html リンク
3. 強み：ナンバリング形式（01〜04）
4. 対象業種：6業種グリッド
5. 写真帯：実写3枚
6. 会社概要テザー：about.html リンク付き横2カラム
7. CTAバナー：大きな電話番号 + Webフォームリンク

### about.html（会社概要）
1. 理念・メッセージ（横2カラム）
2. 会社情報テーブル（屋号/代表/創業/住所/電話/事業内容/対応エリア）
3. 沿革タイムライン（1911年〜現在）
4. 強み（ナンバリング形式 01〜04）
5. CTAバナー

### services.html（サービス）
1. ご利用の流れ：**相談 → 見積もり → 配達** 3ステップ
2. Service 01：酒類・飲料の卸・調達（#sourcing）
3. Service 02：イベント・宴会のお酒提案（#event）
4. Service 03：機材・器具の貸出（#rental）
5. Service 04：定期仕入れ・継続取引（#regular）
6. CTAバナー

### contact.html（お問い合わせ）
1. 左：案内情報（電話番号・住所・営業時間・よくあるご相談）
2. 右：Webフォーム（会社名/担当者名/電話/メール/種別/内容/プライバシー同意）
3. URL パラメータ `?type=` でフォーム種別を自動選択

## データ管理（RESTful Table API）

| テーブル | 用途 |
|---------|------|
| `tables/inquiries` | お問い合わせフォームの送信データ保存 |

### inquiries フィールド

| フィールド | 型 | 内容 |
|-----------|-----|------|
| id | text | UUID（自動） |
| company | text | 会社名・屋号 |
| name | text | 担当者名（必須） |
| phone | text | 電話番号 |
| email | text | メールアドレス |
| inquiry_type | text | お問い合わせ種別 |
| message | rich_text | お問い合わせ内容（必須） |
| submitted_at | datetime | 送信日時 |
